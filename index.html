02 — How I work

From ambiguity to release.

The same loop runs through everything I've done — from a fintech data stack to a national AI program to a government app.

  1. 01

    Discover

    Work backwards from users and policy. Run discovery workshops with leadership and subject experts until the real problem is on the table.

  2. 02

    Define

    Turn it into scoped requirements, user stories and acceptance criteria engineers can build from without guessing.

  3. 03

    Validate

    Design functional, edge-case and accessibility tests. Use data to check the thing actually solves the problem.

  4. 04

    Ship & localize

    Manage dependencies to release, and make sure it reads, flows and complies for Saudi and GCC users.
